## 주요 특징

- 회원 / 비회원 주문, 만14세 미만 보호자 동의 (개인정보보호법)
- 반품·교환 7일 보장, 반품 불가 사유 사전 고지 (전자상거래법)
- 배송 권역 5개 (수도권, 일반지역, 산간·도서, 특수 섬지역, 군부대)와 배송비 변경 이력
- 특수품 분리 배송 / 함께 배송 선택, 부대 단체 주문 중량별 배송비
- 재고 부족 시 문자 알림, 입고 대기(최대 30일) 또는 자동 취소·환불
